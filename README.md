# 클로드 초보자 활용가이드 — 영상 클립 호스팅

교육용 HTML 가이드 **「클로드 초보자 활용가이드」** 에서 스트리밍으로 재생되는 영상 클립을 담고 있습니다. HTML 파일 하나만 있으면 이 저장소(GitHub Pages)에서 영상을 불러와 재생합니다.

## 폴더 구성
- `클로드_초보자가이드_클립/` — 본편 클립 (21개)
- `claude_screen_clips/` — 화면 보충 클립 (17개)
- `클로드_코워크가이드_클립/` — 코워크 클립 (7개)

## 출처 및 저작권
아래 유튜브 영상들을 **학습 목적**으로 구간 발췌·재구성한 클립입니다. 각 영상의 저작권은 원저작자에게 있으며, 원저작자의 요청이 있을 경우 삭제합니다.

- **그린코끼리** — 「클로드 초보자 가이드 2026」, 「클로드 코워크 초보자 가이드 2026」
- **ALINN** — 「요즘 클로드가 그렇게 좋다며? 왕초보도 10분 만에 클로드 마스터하는 방법」
